# ✨ Stone Paper Scissor Game 🎮

A simple **Stone-Paper-Scissor** game built with **HTML, CSS, and JavaScript**.  
This project uses `prompt`, `alert`, and `confirm` dialogs to take user input and show the results.  
It also includes a modern UI design with gradient background and styled button.

---

## 🚀 Features
- 🎨 Attractive gradient background & glowing start button  
- 🖱️ Play against the computer with random choices  
- 🔄 Option to replay the game multiple times  
- 📱 Works on any browser (desktop & mobile)  

## 🕹️ How to Play
1. Open the game in your browser.  
2. Click **Start Game**.  
3. Enter your choice: `stone`, `paper`, or `scissor`.  
4. The computer randomly selects its choice.  
5. The winner is decided:
   - ✊ Stone beats Scissor  
   - 📄 Paper beats Stone  
   - ✂️ Scissor beats Paper  
   - Same choice → 🤝 Draw
